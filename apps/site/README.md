# Sangha site

The marketing landing page, built with Astro and Tailwind v4. Static output, no server code.

```sh
pnpm site:dev     # local preview
pnpm site:build   # static files in apps/site/dist
pnpm site:check   # type check
```

The pebbles come from `apps/web/src/assets/pebbles` (the `@pebbles` alias), so the site always matches the app. Copy: `landing-copy.md`. Design notes: `DESIGN.md`.
